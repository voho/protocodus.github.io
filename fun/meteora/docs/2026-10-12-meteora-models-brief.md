# Meteora — brief for the campaign's new Blender models

This is the contract between the Blender build scripts and the game. Read
`assets/models/MODELS.md`, `tools/blender/common.py` and
`tools/blender/build_ships.py` first: the new models follow the same
pipeline, and the helpers in `build_ships.py` (`loft`, `lathe`, `wing`,
`prism`, `box`, `bar`, `mirrored`, `bvh_of`, `frame_on`, `vent`,
`place_rcs`, `empty`, `weathered`, `panel_lines`, `material`,
`glow_material`, `nozzle_material`, `bake_ship`, `anchor_record`) can be
imported and reused (`import build_ships as S`; importing it builds
nothing). `build_asteroids.py` has the rock sculpting.

Paths below are relative to `fun/meteora/`.

## Rules for every build script

- One script per group, `tools/blender/build_<group>.py`, runnable on its
  own and with model names after `--` to rebuild only those:
  `/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python fun/meteora/tools/blender/build_<group>.py -- <name>`
- Deterministic: fixed seeds, no clock. `METEORA_FAST=1` must give a quick
  geometry iteration (tiny textures, 1 sample), like `build_ships.py`.
- Do **not** edit shared files: `common.py`, `build_ships.py`,
  `build_asteroids.py`, `build_all.py`, `render_previews.py`,
  `assets/models/MODELS.md`, `js/anchors.js`, `tests/models-check.mjs`, or
  any game code. If you need a helper, put it in your own script (or a
  module named after your group, e.g. `tools/blender/harrow_parts.py`).
- Do not run git. Other agents are building other groups in the same tree
  at the same time; touch only the files listed for your group.
- Axis rule (unchanged): model in Blender space with the nose along +Y, top
  along +Z, right along +X; the glTF exporter maps Blender (x, y, z) to glTF
  (x, z, −y), so ships arrive nose along three.js −Z.
- Textures: bake procedural paint to WebP through `common.bake` /
  `common.baked_material` (base colour, tangent normal, packed
  metallic-roughness, emissive). Export with `common.export_glb`. No Draco.
- Previews: Eevee needs a GPU the sandbox does not have, so render with
  `METEORA_PREVIEW_ENGINE=CYCLES /Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python fun/meteora/tools/blender/render_previews.py -- <name> ...`
  (writes `tools/blender/previews/<name>.png`; add
  `METEORA_PREVIEW_EXTRA=<scratch dir>` for front, side, top, rear and close
  views). Look at every preview with the Read tool and iterate until the
  model reads well: clear silhouette at a distance, believable detail up
  close, no holes, no inverted normals, no texture seams that show, no
  floating parts.
- Write the anchors module for each model (format below) from the empties,
  the same way `build_ships.py` writes `js/anchors.js` (`anchor_record`,
  `to_gltf`).
- Write `tests/models-<group>-check.mjs` in the style of
  `tests/models-check.mjs` (you may import `readGlb` and `trianglesOf` from
  it): the file exists and is within its size budget, the triangle count is
  within budget, the textures are WebP, the GLB's length matches the brief
  (±15 %), every anchor named in `js/anchors/<name>.js` exists as a node,
  nozzles exhaust toward +Z, and the animated nodes listed exist. Run it with
  `node tests/models-<group>-check.mjs` from `fun/meteora`.
- Write `tools/blender/notes/<group>.md`: for each model, the triangle count,
  texture sizes, file size, what it looks like and the anchor conventions, in
  the style of `assets/models/MODELS.md` (it will be merged there).
- Time: a full build of your group should finish in under ten minutes.

## Generated anchors module

`js/anchors/<name>.js`, overwritten by the build (placeholders are there
now, estimated by hand; keep the exact shape):

```js
/* Meteora — <name> anchors. GENERATED by tools/blender/build_<group>.py from
   the empties in <name>.glb; do not edit by hand. glTF space, metres: nose
   along -Z, top +Y, right +X. */
export default {
  radius: 0,          // largest distance of any vertex from the origin
  length: 0,          // extent along Z
  nozzles: [{ name, pos: [x, y, z], dir: [x, y, z], size }],  // exhaust dir (+Z-ish); size = exit radius
  muzzles: [{ name, pos }],                                   // gun barrel tips
  rcs: [{ name, pos, dir }],                                  // attitude ports; dir = puff direction out of the hull
  launchers: [{ name, pos }],                                 // missile / torpedo release points
  cockpit: [x, y, z] | null,                                  // nose-camera eye point
  dock: [x, y, z] | null,                                     // where a Tender drone attaches (top of a small craft) or, on the drone, its attach plate
  colliders: [{ pos, r }],                                    // compound collision spheres, together covering the hull closely
  subsystems: [{ name, kind, pos, r }],                       // damageable points; r = hit radius
  turrets: [{ name, pos, up, fwd, size }],                    // turret yaw pivots: up = local up, fwd = barrels at rest
  bays: [{ name, pos, dir }],                                 // launch points; dir = launch direction
  lights: [{ name, pos, color: [r, g, b], blink }],           // beacon lights; blink = period in s, 0 = steady
  nodes: { key: 'nodeName' },                                 // animated nodes the game drives
};
```

Every list is present (empty when unused). Empties in Blender:
`nozzle_*` (exhaust along the empty's local −Y, as in `build_ships.py`),
`muzzle_*`, `rcs_NN` (puff along local +Z), `launcher_*`, `cam_cockpit`,
`dock`, `col_NN` (a sphere: set the empty's uniform scale to the radius in
metres; display type SPHERE), `sub_<kind>_<n>` or `sub_<kind>` (uniform
scale = hit radius), `bay_<n>` (launch along local −Y), `light_<n>` (put
colour and blink in the script, not in custom properties). Nozzle `size` is
the exit radius, set in the script. Turrets are separate mesh nodes (see
below); their `up` is the node's local +Z and `fwd` its local +Y, converted
to glTF space.

### Turrets

A turret is two mesh nodes so the game can aim it: `turret_NN` (the base,
origin at the yaw pivot, sitting on the hull, local +Z = up out of the hull)
with a child `turret_NN_gun` (the barrels, origin at the trunnion, barrels
along local +Y). Give them a small shared baked texture or plain material
factors (glTF factors, no textures) — your choice; keep them under 400
triangles each.

## Art direction

- **Belt Watch** (military): off-white `#d9d6cf`, graphite `#2b2d31`,
  orange accent `#c8642a`, like the existing `fighter.glb` (Kestrel). Clean,
  maintained, purposeful; panel lines, light wear.
- **Belt civilians** (freighters, shuttles, station, ark): working
  industrial — weathered off-white and warm grey, rust-orange `#b8652a`
  cargo paint, hazard stripes `#d9a21b`, numbers and stencils as paint
  blocks, many small lit windows (warm `#ffd9a0`), navigation lights. The
  *Perpetua* is three hundred years old: faded mission teal `#2e6f8e` bands
  on patched off-white plates, mismatched replacement panels, scorched
  dust-shield prow.
- **Harrow** (the machines): gunmetal `#4a4f55`, oxblood `#5e1a1d`, hazard
  yellow `#d9a21b`, red emissive eyes and seams `#ff2a1a`, like the existing
  `interceptor.glb` (Thorn). Faceted, angular, layered plates, tines and
  blades like a harrow plough; nothing has a canopy — they are machines.
  Hidden detail for the story: somewhere on the Mother, a faded off-white
  panel with a teal band, the *Perpetua* program's colours.
- Emissive maps carry windows, lights, eyes and engine throats; the game
  scales emissive by 3 for ships (see `js/models.js`).

## Groups and models

Sizes are lengths along the nose axis; budgets are triangles (all meshes
of the file) and file size.

### Group `craft` — `build_craft.py`

| model | size | tris | file | textures |
|---|---|---|---|---|
| `swift.glb` | 10 m | ≤ 9 000 | ≤ 1.3 MB | base/normal 2048², MR/emissive 1024² |
| `anvil.glb` | 19 m | ≤ 14 000 | ≤ 1.7 MB | base/normal 2048², MR/emissive 1024² |
| `drone.glb` | 3.5 m | ≤ 3 000 | ≤ 0.45 MB | 1024² |
| `torpedo.glb` | 4.5 m | ≤ 1 200 | ≤ 0.25 MB | 512² |
| `shuttle.glb` | 28 m | ≤ 8 000 | ≤ 1 MB | 1024² (emissive windows) |

- **Swift** — Belt Watch interceptor: light, fast, fragile. A slender dart
  with a single large engine, small cranked-delta wings set well aft,
  canards behind the canopy, a long pointed nose, a bubble canopy (separate
  `glass` node like the Kestrel's), guns in the wing roots
  (`muzzle_L/R`), one missile rail under the belly (`launcher_0`), 16 RCS
  ports as on the Kestrel (every axis and turn covered by ≥ 2), `cam_cockpit`,
  `dock` on the spine behind the canopy, `nozzle_C` (size ≈ 0.55). It must
  not read as a shrunk Kestrel: thinner, longer-nosed, one engine.
- **Anvil** — Belt Watch bomber: slow, armoured, strong. Broad and heavy:
  a thick lifting body, two big engines, short thick wings with armour
  plates, a recessed torpedo bay under the belly (`launcher_0`,
  `launcher_1`), two nose guns (`muzzle_L/R`), a rear auto-turret on the
  dorsal tail (`turret_rear` + `turret_rear_gun`, barrels aft), a stepped
  two-seat canopy (`glass` node), `cam_cockpit`, `dock`, 16 RCS ports,
  `nozzle_L/R` (size ≈ 0.8).
- **Tender (drone)** — repair drone: a compact utility body with two folded
  manipulator arms, a welding head, four small thruster pods
  (`nozzle_0..3`, exhaust +Z), a green status light and white work lights
  (`light_*`), Belt Watch paint with a green cross band; `dock` = its attach
  plate underneath.
- **Torpedo** — a heavy torpedo: long cylinder, sensor nose, four fins, a
  motor bell (`nozzle_C`, size ≈ 0.2); off-white with an orange band (the
  game tints a copy dark red for the Harrow's Spike).
- **Skiff (shuttle)** — evacuation shuttle: boxy, practical; a cockpit
  forward, a long passenger cabin with rows of lit windows, two engines aft
  (`nozzle_L/R`, size ≈ 1.2), folded landing struts, civilian paint
  (off-white and warm grey with hazard stripes and a big painted number),
  8–16 RCS ports, `dock`.

### Group `harrow` — `build_harrow.py`

| model | size | tris | file | textures |
|---|---|---|---|---|
| `maul.glb` | 17 m | ≤ 10 000 | ≤ 1.3 MB | base/normal 2048², MR/emissive 1024² |
| `sentry.glb` | 8 m across | ≤ 3 000 | ≤ 0.45 MB | 1024² |
| `seed.glb` | radius 20 m | ≤ 6 000 | ≤ 0.9 MB | 1024² |
| `anchor.glb` | 64 m tall | ≤ 6 000 | ≤ 0.8 MB | 1024² |

- **Maul** — Harrow bomber drone: the Thorn's design language (faceted
  sections, oxblood and gunmetal plates, hazard stripes, a red sensor eye)
  but heavy and hunched: a deep keel, a long torpedo spine slung beneath
  (`launcher_0`), two forward gun blisters (`muzzle_L/R`), twin engines
  (`nozzle_L/R`, size ≈ 0.75), harrow tines along the back, 16 RCS ports.
  No canopy; `cam_cockpit` at the eye.
- **Eye (sentry)** — a watching drone: an armoured sphere with radial blade
  fins and spines, one large red eye at the front; the eye (lens and iris)
  is a separate node `eye` whose origin is the eye's centre, looking along
  Blender +Y, so the game can turn it toward the player. `sub_eye` at the
  eye.
- **Seed** — a seeded nest rock: an asteroid in the style of
  `build_asteroids.py` (radius ≈ 20 m) threaded with Harrow fabricator
  growths — metallic oxblood nodules and pods breaking through the rock, red
  glowing seams and veins (emissive), and three rocket clusters on one side
  (`nozzle_0..2`, exhaust +Z, size ≈ 1.6) that the game lights when a seed
  moves. Its node is `rock`.
- **Fold anchor** — a Harrow interdiction pylon, 64 m tall along Blender +Z
  (glTF +Y): a tripod base, a tall faceted mast with tines, and at the top
  a glowing red emitter cage, the separate node `emitter`. `col_*` spheres
  along the mast, `sub_emitter` at the top.

### Group `mother` — `build_mother.py`

| model | size | tris | file | textures |
|---|---|---|---|---|
| `mother.glb` | ~800 m | ≤ 60 000 | ≤ 4 MB | up to two 2048² sets; turrets and nodes may use factors |

The Harrow foundry ship. A long armoured spine with ranks of harrow tines
and blades along its back (like a plough turned upside down), fabrication
arms folded along the flanks, two launch bays under the forward hull
(`bay_0`, `bay_1`, launch downward/forward), two shield generator domes on
the upper flanks (`sub_shield_0/1`, emissive red), a reactor at the
heart behind an armoured cage — the reactor sphere is a separate node
`reactor` (red-orange emissive; origin at its centre) and `sub_reactor`
sits there — a great red eye in the prow (node `eye`), a beam emitter
in the prow (`sub_beam`), two engine clusters aft (`sub_engine_0/1`, nozzles
`nozzle_0..`, size ≈ 25–30), eight turrets (`turret_00..07` + `_gun`)
spread over the hull with clear arcs, many small red running lights and
seams. Colliders `col_*` hug the hull (40–80 spheres). Subsystems also
`sub_bay_0/1` at the bays. One faded off-white plate with a teal band
somewhere on the hull (story detail). It must read as huge: layered detail
at several scales, kitbashed greebles, deep recesses, lit seams.

### Group `perpetua` — `build_perpetua.py`

| model | size | tris | file | textures |
|---|---|---|---|---|
| `perpetua.glb` | ~1400 m | ≤ 65 000 | ≤ 4 MB | up to two 2048² sets |

The three-hundred-year-old generation ship, now the belt's carrier. A long
truss spine; a massive dish-shaped dust shield on the prow (scorched,
patched); behind it the command section (`sub_bridge`); amidships a
habitat ring on spokes, a separate node `ring` whose origin is on the
ship's axis so it can turn about the spine (lit windows round the rim); a
hangar module with a big lit bay mouth (`sub_hangar`, `bay_0` launching
downward/outward); fuel and cargo tank clusters; three fusion engines aft
(`nozzle_0..2`, size ≈ 35, `sub_engine_0..2`); ten point-defence turrets
(`turret_00..09` + `_gun`); radiator wings; antennae; nav lights
(`light_*`, red to port, green to starboard, white strobes). Off-white
plates with faded teal mission bands, mismatched replacement panels.
Colliders `col_*` hug the hull and ring (50–90 spheres).

### Group `civil` — `build_civil.py`

| model | size | tris | file | textures |
|---|---|---|---|---|
| `freighter.glb` | ~110 m | ≤ 14 000 | ≤ 1.5 MB | 2048² base/normal |
| `station.glb` | ~450 m across | ≤ 45 000 | ≤ 3.5 MB | up to two 2048² sets |
| `colony.glb` | ~900 m | ≤ 45 000 | ≤ 3.5 MB | up to two 2048² sets |

- **Mule (freighter)** — an ore freighter: a cab with a bridge window band
  forward (`sub_bridge`), a long spine carrying ore containers and hoppers,
  a drive section aft with one big and two smaller engines
  (`nozzle_C/L/R`, sizes ≈ 3.2 / 2.4, `sub_engine_0`); rust-orange cargo
  paint, hazard stripes, painted numbers, nav lights, `dock` on top.
  Colliders along the hull.
- **Varlaam (station)** — a mining settlement built into a large asteroid
  (radius ≈ 150 m, sculpted as in `build_asteroids.py`): habitat towers and
  domes rising from the rock with many lit windows, a docking ring on a
  pylon at the front (`sub_dock`, `bay_0` launching forward), ore
  conveyors and gantries, solar arrays, a comms mast (`sub_comms`), a
  reactor block (`sub_reactor`, emissive vents), six defence turrets
  (`turret_00..05` + `_gun`), nav and work lights. Colliders cover the rock
  and the structures. It should look lived-in.
- **Long Mercy (colony ark)** — an evacuation ark assembled in a hurry
  from freighter modules and *Perpetua* spares: a long, chunky, asymmetric
  stack of cylindrical habitat and cargo modules with lit windows, girders
  and patch plates; at the bow the fold drive: a huge ring (inner radius
  ≈ 120 m) on struts, a separate node `drive` with emissive coils (the game
  pulses it as it charges; origin at the ring's centre); `sub_drive` there
  (r ≈ the ring's inner radius); two engines aft (`nozzle_0/1`, size ≈ 30,
  `sub_engine_0/1`); four turrets (`turret_00..03` + `_gun`). White and warm
  grey with teal and gold bands. Colliders along the stack and around the
  ring (not across its opening — ships fly through it).

### Group `fleet` — `build_fleet.py`

More classes so the fight varies by size, armour, firepower and speed.

| model | size | tris | file | textures |
|---|---|---|---|---|
| `mite.glb` | 5 m | ≤ 2 500 | ≤ 0.4 MB | 1024² |
| `talon.glb` | 13 m | ≤ 10 000 | ≤ 1.3 MB | base/normal 2048², MR/emissive 1024² |
| `warden.glb` | ~140 m | ≤ 24 000 | ≤ 2.2 MB | 2048² |
| `halberd.glb` | ~160 m | ≤ 26 000 | ≤ 2.4 MB | 2048² |

- **Mite** — a Harrow swarm drone that hatches from Seeds in packs: tiny,
  fast and fragile. A compact faceted body with a single big red eye, two
  short blade wings, one engine (`nozzle_C`, size ≈ 0.35), one gun
  (`muzzle_C` under the eye). 8 RCS ports are enough. Must read at a glance
  as "small and many".
- **Talon** — a Harrow heavy fighter: tougher, slower and better armed than
  the Thorn. Broader, armoured plates over the cockpit-less nose, twin heavy
  gun barrels (`muzzle_L/R`), missile racks on the wing roots
  (`launcher_0/1`), two engines (`nozzle_L/R`, size ≈ 0.6), forward-swept
  tines, 16 RCS ports, a red eye (no canopy).
- **Warden** — a Harrow escort corvette, ~140 m: a long faceted wedge with
  plough tines along the keel, a red eye at the prow, four turrets
  (`turret_00..03` + `_gun`), an engine block aft (`nozzle_0..`, size ≈ 6,
  `sub_engine_0`), `sub_bridge` (its "brain" behind the eye), colliders.
- **Halberd** — a Belt Watch gunship, ~160 m, the relief fleet's backbone:
  a stocky armoured hull in Watch off-white, graphite and orange, a raised
  bridge tower (`sub_bridge`), six turrets (`turret_00..05` + `_gun`) with
  clear arcs, two engine nacelles (`nozzle_0/1`, size ≈ 7, `sub_engine_0/1`),
  a small hangar slot, many small lit windows, nav lights, colliders.
