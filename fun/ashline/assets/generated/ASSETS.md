# Ashline visual assets

Generated for this project with the built-in `image_gen` tool on 2026-09-05. No external stock art or image API/CLI was used. The current unit atlas is lossless WebP; the earlier building, prop, and ground exports use quality 94. The browser normalizes atlas cells once, removes the unit chroma key, and creates the opposing faction's red paint variant.

The shared art direction is realistic pre-rendered military miniatures: weathered ivory armor, graphite mechanisms, restrained blue/cyan faction markings, warm work lights, charcoal basalt and mint mineral deposits. The interface uses the same charcoal, ivory, cyan and amber palette.

| File | Contents |
| --- | --- |
| buildings.webp | Command nexus, reactor, refinery, barracks, foundry and rail sentry; 3×2 RGBA atlas |
| units-topdown.webp | Current unit roof atlas; 3×2 cells: rifle idle, rifle walking, rover / tank, artillery, hauler |
| props.webp | Three basalt outcrops and three crystal deposits; 3×2 RGBA atlas |
| ground.webp | Seamless basalt/ash ground material |

`assets.js` rotates each unit's overhead texture continuously on the ground plane, then applies the same 0.88 vertical foreshortening and shallow screen-space side depth to every heading. The result is the requested mostly overhead view with a small amount of visible side depth. Unit classes are normalized separately; the two infantry poses share one scale and are registered to the same body anchor. Contact shadows and side walls retain fixed screen-space direction. Construction, lights, steam, tracks, fog and combat effects remain animated in the renderer. The original PNG generations remain in the Codex generated-images directory; the game references only project-local WebP assets.

The five earlier directional sheets (`tank.webp`, `scout.webp`, `artillery.webp`, `harvester.webp`, and `rifle.webp`) are retained as historical sources and are no longer loaded. Their oblique/side-facing instructions below are superseded by the current unit camera and `../../AGENTS.md`.
