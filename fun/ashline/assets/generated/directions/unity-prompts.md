# AI Unity directional sprite provenance

Generated with the built-in `image_gen.imagegen` tool on 2026-09-27. Each sheet contains separately generated views of the same unit; no direction was synthesized by rotating one source sprite. Final PNG outputs were converted losslessly to WebP with Pillow, preserving the original RGBA pixels. No color key, painting, or source-view rotation was applied during conversion.

## Atlas layout

- `unityRifle.webp` and `unityRocket.webp`: 4 columns × 4 rows. First eight frames are idle E, SE, S, SW, W, NW, N, NE; next eight are alternate walking poses in the same order.
- All other `unity*.webp`: 4 columns × 2 rows, E, SE, S, SW, W, NW, N, NE.
- Canvas sizes are 1254 × 1254 for infantry and 1774 × 887 for vehicles. Cell boundaries are fractional; the runtime splits by normalized dimensions and isolates each sprite's connected silhouette within padded source regions.
- Fixed mostly-overhead orthographic camera, shallow visible sides, stationary upper-left lighting, transparent background without cast ground shadows. Ground shadows are generated separately by the renderer.
- `unityHarvester` has an empty hopper in each generated view; runtime cargo is a separate layer.

All final sheets were visually inspected for direction order, camera, whole silhouettes, and identifying equipment. Scout and artillery received a generated layout repair; constructor received a generated repair of its three northern views. Originals and rejected iterations remain outside the project at the built-in output location.
