# Desktop interaction review

Every management panel uses the upper-left corner beside the map. Opening a new primary panel closes the previous management or inspection surface; the optional objective chip yields that space. The map centre remains available for construction and exploration. Panels scroll within short computer windows, retain keyboard focus, and respect reduced-motion preferences.

| Flow | Likely next action | Interface behavior |
| --- | --- | --- |
| Start or load a world | Explore, then build | Startup remains a separate focused choice; the playable map starts with secondary panels closed. Unsupported phones and tablets never enter it. |
| Build a road or railway | Add stops near customers | Completion returns to Build with an **Add stops** action. **Done** also returns to the picker. |
| Place a road stop | Connect another stop, then launch | Bare suitable land includes the road underneath in the quoted price. Both pieces validate funds and ground first and undo together. Completion offers **Create a route** and **Add another stop**. Rail stations require tracks; ports and airports keep their own placement rules. |
| Pick a route stop | Find matching stations on the map | Matching stops are emphasized; other buildings and trees become translucent. The banner names start/end and the matching stop count. Choosing the start continues directly to the end; choosing both returns to the draft. Reduced motion uses steady highlighting. |
| Browse routes | Find or inspect an existing service | The route list contains services and search. Filters, per-route fleet/earnings, fleet upgrades and contract offers expand on request. Creation and editing each occupy a separate screen with **Back to routes**. |
| Create or edit a route | Confirm connection and launch/save | Only that draft is shown. Stops, cargo and the checked connection precede the action. Launch or save returns to the list and emphasizes the affected route. |
| Inspect a stop or production site | Carry its supply or satisfy demand | Existing cargo actions start a prefilled route draft; references keep their inspection Back history. The inspector replaces the management drawer. |
| Browse buildings and objects | Understand purpose, then place or follow production | Gallery presents current artwork and definition data. Build selects the corresponding tool; production links open the chain explorer. |
| Browse production chains | Find or build the next supplier/customer | The existing chain explorer retains resource selection, map locations, and build/locate actions in one focused dialog. |
| Manage fleet or company | Act on an identified service or financial need | Existing route-specific vehicle actions and company ledger remain contextual; optional upgrades and loan details use disclosure. |
| Save, load or retire | Confirm the exact replacement/removal | Existing inline save confirmations and retirement confirmations preserve explicit outcomes and keyboard return. Opening a dialog pauses the world and closing it restores the prior speed. |
| Change map options or read help/news/goals | Return to the map | Secondary surfaces share the same upper-left anchor and close their competing panels. Time and remembered terrain-height controls remain adjacent in the header. |

The changes focus on repeated construction and route decisions. Save integrity, economics, simulation cadence and phone policy remain governed by their existing model and project decisions.
