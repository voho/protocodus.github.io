# Desktop interaction review

Every management panel uses the upper-left corner beside the map. Opening a new primary panel closes the previous management or inspection surface; the optional objective chip yields that space. The map centre remains available for construction and exploration. Panels scroll within short computer windows, retain keyboard focus, and respect reduced-motion preferences. The main measure is the number of steps in common workflows: frequent actions stay visible, while focused panels hold optional detail. Related activities use labeled buttons; primary, secondary, selected and destructive actions share one rounded button style. Standard controls are 36 px tall, with 32 px controls in compact lists.

| Flow | Likely next action | Interface behavior |
| --- | --- | --- |
| Start or load a world | Explore, then build | Startup remains a separate focused choice; the playable map starts with secondary panels closed. Unsupported phones and tablets never enter it. |
| Select a construction tool | Build immediately | Road, Railway, Stop and Clear live in the main toolbar, with keyboard shortcuts and active state. Network, Buildings, Industry and Terrain open focused tool pickers with related activity buttons. Buildings separates Zones & towns from Place buildings; Industry separates Suppliers from Factories. Gallery is in Menu → Map and linked from inspectors. |
| Inspect a road or railway | Add the matching stop | A priced Build road stop / Build rail station action constructs on the selected tile and supports Undo. Crossings offer both choices; an existing stop opens its own inspector. The rail stop has a station house and platform canopy. |
| Build a road or railway | Add stops near customers | Completion returns to Build with an **Add stops** action. **Done** also returns to the picker. |
| Place a road stop | Connect another stop, then launch | Bare suitable land includes the road underneath in the quoted price. Both pieces validate funds and ground first and undo together. Completion offers **Create a route** and **Add another stop**. Create a route immediately asks for a destination on the map, with the new stop already selected; **Choose from list** returns to the equivalent dropdown. Rail stations require tracks; ports and airports keep their own placement rules. |
| Pick a route stop | Find matching stations on the map | Matching stops are emphasized; other buildings and trees become translucent. The banner names start/end and the matching stop count. Choosing the start continues directly to the end; choosing both returns to the draft. Starting a new route from an existing stop begins destination picking immediately; Choose from list, Cancel and Escape keep the prefilled draft. Reduced motion uses steady highlighting. |
| Browse routes | Find or manage an existing service | The route list exposes a priced **Add vehicle** action, fleet count and current earnings on each card, with direct **Map**, **Edit** and **Manage** alternatives. Manage route separates **Fleet** and **Earnings**, with direct Edit, Retire and repair actions. Creation and editing each occupy a separate screen with **Back to routes**. |
| Create or edit a route | Choose stops, cargo and fleet | Only that draft is shown. Choose start/end, then supplied cargo, then an automatic or manual name and vehicle quantity. Total cost and approximate revenue/net remain visible, with a blinking connected map preview. An existing service receives the requested extra vehicles. Editing keeps the fleet. Launch or save returns to the list. |
| Inspect a stop or production site | Carry its supply or satisfy demand | Labeled cargo actions start a prefilled route draft; the nearest buyer and up to two suppliers offer direct prefilled route actions. A stop shows its first two services and covered places directly. Further alternatives, stock and conditions open only when needed. Disclosures keep their state across live refreshes. References keep inspection Back history. The inspector replaces the management drawer. |
| Browse buildings and objects | Understand purpose, then place or follow production | Gallery presents current artwork and definition data. Build selects the corresponding tool; production links open the chain explorer. |
| Browse production chains | Find or build the next supplier/customer | The existing chain explorer retains resource selection, map locations, and build/locate actions in one focused dialog. |
| Manage fleet or company | Act on an identified service or financial need | Company separates Overview, History, Routes, Property and Loan. A vehicle offers Follow, Show route, a direct link to its route’s Fleet view and a priced Add vehicle action. A disconnected or unaffordable draft links to construction or Loan options and preserves the draft for return. |
| Save, load or retire | Confirm the exact replacement/removal | Saved games separates Save current and Load worlds. Save before loading returns to the same load confirmation after a successful named save. Labeled Replace, Rename and Delete controls retain explicit outcomes and keyboard return. Opening a dialog pauses the world and closing it restores the prior speed. |
| Change map options or read help/news/goals | Act, then return to the task | Layers is directly available on the map, with six Essentials and a separate More layers view. Closing it restores the originating management screen and draft. Menu separates Game, Company, Map and Help into short groups, retaining a Map layers alternative. Guide separates Build, Routes, Growth and Resources with direct action buttons; Company goals shows one chapter at a time and links to its next action. Secondary surfaces share the upper-left anchor and close competing panels. |

The changes focus on repeated construction and route decisions. Save integrity, economics, simulation cadence and phone policy remain governed by their existing model and project decisions.

Common workflow checks count actions from the current surface: adding a vehicle, editing a route, planning from a supplier/buyer and opening a vehicle’s fleet take one click. Starting from a stop needs one click before choosing a destination; opening Layers needs one click. Optional list selection, alternate suppliers/buyers and the complete management views remain available.
