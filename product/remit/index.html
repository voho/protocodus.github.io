Digital reverberator · Reason Rack Extension (in development)

Remit

Five digital studio reverbs from 1976 to 1986. Each runs its own converters, sample rate and delay tank in real time, with no impulse responses, so a tail grows, moves and fades the way the machine made it.

  • Five machines
  • Four programs
  • Quad rear outputs
  • 20 patches

The machines

Five machines, each with its own converters.

Remit recreates the years when studio reverb first went digital. The filters around the converters, the converters at each machine’s own sample rate and word length, and the delay tank all run as the machine ran them, so the grit of 1976’s 12-bit converter sits beside the cleaner 16-bit sound of 1985 and 1986.

  • Five machines

    Pick 1976, 1979, 1981, 1985 or 1986. Each has its own sample rate, converters and tank, and the knobs move in the steps or ranges that machine had.

  • Four programs

    Reverb, the long Space, the gated Non-Lin, and Origin, which runs the 1976 tank inside a later machine’s converters. Each machine offers the programs it had.

  • Six large knobs

    Decay, Low, Mid, High, Filter and Predelay shape the tail. The early reflection and cluster knobs work on the machines that have them; a control a machine lacks goes dark.

  • A live display

    The green display shows the input level and converter clipping, the reflections, the energy in the four tank loops, every reverb control’s value in seconds, kHz or ms, and the output meters.

  • Smooth under automation

    Every knob moves without clicks or zipper noise, and changing machine or program fades the tail out and back in. Input drives the converter, Output trims the reverb, and Mix sets dry against wet with no latency.

In the rack

Quad outputs on the back.

On 1976 and 1985 a second, rear stereo pair (Ch III and IV) carries the quad output beside the main pair. Cable it to a second mixer channel and pan the pairs apart for a quad hall. The back draws the signal flow and lights each bus while it is live.

In tests Remit uses 0.4 to 0.6 % of one core across every machine and program at 48 kHz, on the development machine; Reason’s own CPU figure is not measured.

Reason Rack Extension

Put it on a send.

Find Remit among the effects in Reason’s browser and put it on a send; it opens on the patch 1976 Hall. Play something short, such as drums, try the five machine keys, change the program and move Decay. If CLIP lights on the display, turn Input down.

Rack Extension version history

Remit version history.

The Rack Extension is in development and not yet in the Reason Shop.

0.4.1f1 Release candidate · 18 November 2026 · built

Input, Mix and Output changed while Remit is resting, such as a patch chosen with the transport stopped, now take effect at once, so the next sound no longer starts too loud. The sound of every setting is otherwise unchanged; the back prints the new number.

0.4.0f18 Release candidate · 17 November 2026 · built

The cream broadcast panel: a cream plate with brown panels, black bakelite knobs, chrome keys under jewel lamps and the display in a dark bezel. The panel grows to 5U so every caption reads. The sound, parameters and patches are unchanged.

0.4.0f16 Release candidate · 17 November 2026 · built

Remote names match the panel: Machine and Early Pan.

0.4.0f15 Release candidate · 17 November 2026 · built and uploaded

The first build Reason’s developer portal renders and previews. The sound, parameters and patches are unchanged.

0.4.0f1 Release candidate · 16 November 2026 · built

A new panel, and a display that prints Decay, Low, Mid, High, Filter and Predelay in seconds, kHz or ms. Every automatable control now changes without a click, and changing machine or program fades the tail out and in. The steepest decay tilts keep their shape instead of muting or ringing on, and leaving bypass fades the dry signal.

0.3.0d1 Development build · 15 November 2026

The first Rack Extension: the five machines, four programs and a live display of the converters and tank.
